# רשימת תמונות נדרשות

כרגע הדף עובד עם **placeholders ב-SVG** (ראית? לכל אחד צבע ושם שונה).
החלפה לתמונות אמיתיות בשני שלבים פשוטים:

## שלב 1 — שמרו את התמונות בתיקייה הזו

שמרו את התמונות באותם שמות *בדיוק* (אבל עם סיומת `.jpg`/`.png`/`.webp` במקום `.svg`).
המלצות: רוחב מינימלי 1200px, פורמט JPG או WEBP, איכות גבוהה.

## שלב 2 — עדכון הקוד (find & replace בודד)

פתחו את הקבצים הבאים והחליפו `.svg` → `.jpg` (או `.webp`):

- `src/components/Hero.tsx` — 2 תמונות (logo + hero)
- `src/components/FacilitiesGallery.tsx` — 8 תמונות
- `src/components/Footer.tsx` — 1 תמונה (logo)

אפשר להחליף הכל בבת אחת ב-IDE עם find & replace בתיקיית `src/`.
אחרי שתחליפו, גם תוכלו להסיר את הדגל `unoptimized` כדי שNext יעבור לאופטימיזציה אוטומטית.

## טיפים

- כל תמונה תקבל אוטומטית גרדיאנט שחור מלמטה — שמרו על נושא ברור במחצית העליונה.
- במחצית התחתונה מופיע טקסט (שם המתקן + משפט רגשי) — שמרו על שטח חלק.
- אם תמונה חסרה, לא יישבר הדף — מוצג ה-SVG placeholder עד שתעלו את האמיתית.
